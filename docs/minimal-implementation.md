# エディターの操作

## 起動

```sh
npm run dev
```

開発サーバーの`/`がエディター、`/viewer.html`が書き出したGLBを確認するビューアー。初期状態は正面レイヤー2枚と地面1枚で、`public/samples/`の画像を読み込む。

## 配置する

1. 「基準設定」で2D換算解像度・基準面の高さ・垂直FOVを指定し、「適用」を押す。
2. 一覧からレイヤーを選び、「画像」でPNG・JPEG・WebPを読み込む。「追加」は画像から新しい正面レイヤーを作る。画像はブラウザー内で処理し、外部へ送信しない。
3. 「基準面との関係」と「向き」を選ぶ。平行は正面、垂直は下（地面）・上（天井）・左（壁）・右（壁）。
4. 「配置 · px」と「配置基準点 · px」で位置・寸法を編集する。シーン単位で入力したい場合は「3D配置」を開く。どちらから編集しても同じ配置へ反映する。

正面のX・Y・幅・高さは、共通キャンバス左上を基準にした画面上の矩形。Xは右、Yは下が正。それ以外のpxは、基準面の縮尺を空間に適用した**px相当値**で、基準面中央が原点、Xは右・Yは上・Zは手前が正となる。

- 正面：矩形と奥行きZを指定する。「Z変更時の配置」で2D配置／3D配置の保持を選ぶ。
- 地面・天井：中心X・幅・手前端Z・奥端Zを指定し、高さは配置基準点Yで変える。
- 左右壁：中心Y・高さ・手前端Z・奥端Zを指定し、左右位置は配置基準点Xで変える。

配置基準点を動かすと面も同じ量だけ動く。基準点Zは0固定。入力欄の近くの「基準面 Z = 0」や辺の座標を配置の目安にできる。初期地面のYはpx相当で-540、シーン単位で-2.5。

画像はアスペクト比を維持した中央coverで配置する。比率が共通キャンバスと異なる場合は画像欄の近くへ通知する。画像の各辺は使用中のGPUのテクスチャ寸法上限で確認する。ファイル容量や解像度の固定上限は設けない。

## 見え方を確認する

- **プレビュー**：左右・上下スライダーで表示用カメラを動かす。「基準へ戻す」で元の視点へ戻る。編集データの基準カメラは動かない。
- **2D合成**：入力画像を各面の中心Zの順に奥から手前へ重ねる。同じZでは一覧順。3D形状の変形や面の交差は再現しない。
- **配置確認**：ドラッグで回転、ホイールで拡大縮小、右ドラッグで移動。「画像／範囲／識別色」を切り替える。範囲表示の橙ハッチは基準枠外、赤は投影不可を表す。

「周囲を表示」はプレビューの基準枠外を見るための操作。FOV自体を変える場合は「基準設定」から適用する。具体的な補正は[仕様のFOV調整](./specification.md#編集モデルの正本と3d入力実装済み)を参照。

## レイヤーを整理する

選択したレイヤーは「削除」できる。「上へ／下へ」は一覧順だけを変え、3D配置は変えない。枚数に固定上限はない。全削除後も再追加できる。画像選択のキャンセルや読み込み失敗では追加しない。

## 保存して利用する

| 操作 | 用途 |
| --- | --- |
| JSON保存 | 基準設定・一覧順・配置・元画像を`three-layered-scene.json`へ保存し、再編集に使う |
| JSON読み込み | 検証後に編集内容を置き換える。失敗時は現在の内容を残す |
| GLB書き出し | 表示中の面・画像・基準カメラを`three-layered-scene.glb`へ出力し、表示側へ渡す |

自動保存はない。画像は再圧縮せず保存し、一時的な確認用カメラや表示設定は保存しない。GLBの頂点UVは8×8 Gridによる近似プレビュー用で、専用表示はextrasからTSL投影を復元する。投影カメラの背面・near/far外に頂点がある面はGLBへ書き出せない。

GLBは`/viewer.html`で選択して確認できる。別プロジェクトで使う場合は[最小限の使用例](./glb-projection.md#別プロジェクトでの最小限の使用例)を参照。詳細な仕様・未対応機能は[仕様](./specification.md)にまとめる。
